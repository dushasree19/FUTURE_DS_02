# Social Media Campaign Performance Dashboard

## Internship Track
Data Science & Analytics – Future Interns

## Task Objective
The objective of this task is to analyze social media advertising campaign data and evaluate campaign performance using key marketing metrics such as CTR, CPC, and Conversion Rate.

## Tools Used
- Power BI
- CSV Dataset
- Data Analysis & Visualization

## Dataset Description
The dataset contains Facebook ad campaign data including:
- Ad Spend
- Impressions
- Clicks
- Campaign IDs
- Total Conversions
- Approved Conversions

## Key Metrics Created
- Click Through Rate (CTR)
- Cost Per Click (CPC)
- Conversion Rate

## Dashboard Features
- KPI cards for CTR, CPC, and Conversion Rate
- Campaign-wise CTR analysis
- Ad Spend vs Total Conversions scatter analysis
- Visual insights to identify high-performing campaigns

## Key Insights
- Higher ad spend does not always guarantee higher conversions
- Certain campaigns achieve better conversion efficiency
- CTR varies significantly across campaigns
